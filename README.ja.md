# 易占 · 周易六爻排盤

**[中文](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md)**

フロントエンドのみで実装された周易六爻占い・排盤サイトです。銭貨法、数字法、時間法の 3 つの起卦方式をサポートし、本卦（もとはけ）、之卦（してきか）、互卦（こか）、納甲、六亲、六神、世応を自動で排布します。バックエンドやデータベースは不要で、ブラウザを開くだけでご利用いただけます。

**オンライン版：https://zhouyi-master.surge.sh**

---

## 機能

### 3 つの起卦方式

| 起卦方式 | 説明 |
|---------|------|
| 🪙 **銭貨起卦** | 6 回の結果（6/7/8/9）を手動入力、または「オンライン起卦」で 3 枚の銭貨をシミュレート |
| 🔢 **数字起卦** | 3 つの数字を入力し、先天八卦数で上卦・下卦・動爻を算出 |
| ⏰ **時間起卦** | 梅花易数法により、現在の年月日時の数字から自動起卦 |

### 排盤出力

- **本卦**：卦名、卦辞、大象、卦象記号
- **口語訳**：一言まとめ・キーワード・核心アドバイス
- **占問別解釈**：恋愛 / 仕事 / 金運 / 健康 / 受験
- **之卦（変卦）**：動爻が変化した後の卦象
- **互卦**：2・3・4 爻を下互、3・4・5 爻を上互とする
- **納甲六亲**：各爻の干支・五行・六亲関係
- **六神配置**：日の天干に応じて青龍・朱雀・勾陳・騰蛇・白虎・玄武を配置
- **世応定位**：世爻と応爻を自動表示
- **日干支**：当日の日柱を自動計算
- **今日の開運**：ラッキーカラー・数字・方位・宜忌・座右铭
- **結果シェア**：シェアカード画像の生成、またはテキストをコピー
- **マルチプラットフォームカード**：微信朋友圈 9:16、小紅書 3:4、微博 / Instagram 1:1
- **シェア可能なリンク**：各卦象結果に独立した URL hash を持たせる

## 技術構成

- **純粋な静的フロントエンド**：HTML5 + CSS3 + Vanilla JavaScript
- **バックエンド不要**：すべての排盤演算はブラウザ内で完結
- **外部 API 不使用**：第三者 API を一切呼び出さない
- **レスポンシブデザイン**：Apple 風グラスモーフィズム UI、PC / モバイル対応

## ローカル実行

本プロジェクトは静的サイトのため、ビルド不要です。

```bash
cd zhouyi-web
python -m http.server 8080
# http://localhost:8080 を開く
```

または：

```bash
npx serve .
```
