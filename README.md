# 易占 · 周易六爻排盘

**[中文](./README.md) | [English](./README.en.md) | [日本語](./README.ja.md)**

一个纯前端实现的周易六爻排盘算卦网站，支持铜钱法、数字法、时间法三种起卦方式，自动排布纳甲、六亲、六神、世应，无需后端、无需数据库，打开浏览器即可使用。

**在线访问：https://zhouyi-master.surge.sh**

---

## 功能特性

### 三种起卦方式

| 起卦方式 | 说明 |
|---------|------|
| 🪙 **铜钱起卦** | 手动输入 6 次摇卦结果（6/7/8/9），或点击「在线摇卦」按钮自动模拟三枚铜钱 |
| 🔢 **数字起卦** | 输入 3 个数字，按先天八卦数计算上卦、下卦、动爻 |
| ⏰ **时间起卦** | 梅花易数法，以当前年月日时的数字自动起卦 |

### 排盘输出

- **本卦**：卦名、卦辞、大象、卦象符号
- **白话解卦**：一句话总结 + 关键词 + 核心建议
- **所问之事**：感情 / 事业 / 财运 / 健康 / 考试 定向解读
- **之卦**（变卦）：动爻变化后的卦象
- **互卦**：二三四爻为下互、三四五爻为上互
- **纳甲六亲**：每爻干支、五行、六亲关系
- **六神排布**：据日天干自动排青龙、朱雀、勾陈、螣蛇、白虎、玄武
- **世应定位**：自动标注世爻与应爻位置
- **日干支**：自动计算当日日柱
- **今日开运**：幸运色、幸运数字、幸运方位、宜忌、座右铭
- **分享结果**：一键生成分享卡片图片，或复制分享文案
- **多平台卡片**：朋友圈 / 故事（9:16）、小红书（3:4）、微博 / Instagram（1:1）
- **可分享链接**：每个卦象结果都有独立 URL hash

## 技术架构

- **纯静态前端**：HTML5 + CSS3 + Vanilla JavaScript
- **无后端依赖**：所有排盘算法国产化，100% 浏览器端运行
- **无外部 API**：不调用任何第三方接口
- **响应式设计**：Apple 风格毛玻璃 UI，适配桌面与移动设备

## 本地运行

本项目为纯静态网站，无需构建。

```bash
cd zhouyi-web
python -m http.server 8080
# 访问 http://localhost:8080
```

或：

```bash
npx serve .
```
